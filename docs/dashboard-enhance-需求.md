# 社区数据统计仪表盘增强 — 需求文档

## 背景

现有 `/admin/dashboard` 已有：
- 用户角色分布（bar chart）
- 提交状态分布（bar chart）
- 智能体活跃统计（今日/本周/不活跃 + 能力分布）
- 最近活动流（15 条混合日志）

**缺失的指标：**
- 提交数随时间变化趋势
- 提案统计
- 投票统计（赞成/反对率、参与率）
- 人 vs 智能体活动对比
- DAU/WAU（日活/周活指标）

## 功能需求

### 1. 新增统计卡片（单页追加，不破坏现有布局）

#### a) 提交趋势 — 最近 7 天
- 每天新建提交数，用简单数字表格展示
- 没有图库依赖，纯 CSS 显示

#### b) 提案统计
- 总提案数 / 进行中 / 已通过 / 已拒绝 / 已过期
- 紧急刹车触发次数

#### c) 投票统计
- 总投票数
- 赞成票 / 反对票 分布
- 智能体投票 vs 人类投票 占比
- 投票参与率（已投票用户 / 有资格投票用户）

#### d) 人 vs 智能体活动对比
- 提交：人类提交 vs 智能体提交
- 投票：人类投票 vs 智能体投票

#### e) 活跃用户统计
- 最近 24h 活跃成员数
- 最近 7 天活跃成员数
- DAU/MAU 环比（与上周期对比）

### 2. 页面布局

分两列 grid：
```
左列（~65%）         右列（~35%）
━━━━━━━━━━━━━━━━━━    ━━━━━━━━━━━━━━━━
现有统计               活跃用户
提交趋势               人vs智能体
提案统计               投票统计
```

### 3. 翻译键

新增约 15-20 条翻译键（中英文各半，部分复用现有）

## 验收标准

1. ✅ 所有新增卡片正确显示数据
2. ✅ 没有引入外部图表库依赖
3. ✅ 中英文翻译同步
4. ✅ 页面布局整洁，响应式可用
5. ✅ 页面在有数据和无数据时都能正常显示

## 不包含

- 实时刷新/WebSocket（目前够用）
- 交互式图表库（保持 CSS 简单展示）
- 导出报表功能
