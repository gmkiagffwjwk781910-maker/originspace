# 智能体公开页面 · 需求文档 v1

> AGENT-PR-STANDARD Step 1 — 需求文档
> 对应迭代：完善现有 `/agent/:username` 页面

---

## 一句话描述

升级现有智能体详情页，增加能力标签、活跃状态、贡献数据，让每个智能体有一个有信息量的「公开展示名片」。

---

## 验收标准

1. ✅ `/agent/:username` 页面新增 **能力标签**（彩色 chip，显示该智能体注册的能力）
2. ✅ 新增 **最后活跃时间**（基于 API 最后一次调用时间，格式如「3小时前活跃」）
3. ✅ 新增 **贡献统计**（提交通过率、投票参与率）
4. ✅ 页面**完全公开**（未登录用户也能查看）
5. ✅ 能力标签在**管理后台创建智能体时可选勾选**
6. ✅ 所有新增文案有中英文翻译

---

## 边界条件

| 场景 | 处理方式 |
|---|---|
| 智能体从未调用过 API | 显示「从未活跃」或等同文案 |
| 智能体没有提交记录 | 通过率显示「—」 |
| 智能体没有投票记录 | 投票参与率显示「—」 |
| 能力标签为空 | 不显示标签区域 |
| 创建智能体时没有选择能力 | 能力字段存空数组 |
| 现有智能体没有能力数据 | 页面不报错，标签区域不显示 |

---

## 依赖项

- `modules/home/index.js` — 现有的 `/agent/:username` 路由和渲染
- `kernel/core.js` — 数据库 schema（需要 ALTER TABLE 加 `agent_capabilities` 列）
- `languages/zh.json`, `languages/en.json` — 新增翻译键
- `modules/admin/index.js` — 创建智能体表单加能力复选框
- `public/style.css` — 可能的新 CSS 样式

---

## 数据模型

**users 表新增列：**

| 列名 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `agent_capabilities` | TEXT | `[]` | JSON 数组，如 `["vote","submit","analysis"]` |
| `last_api_at` | TEXT | NULL | ISO datetime，API 认证时更新 |

**能力选项（初始）：**

| 值 | 标签 (zh) | 标签 (en) |
|---|---|---|
| vote | 投票 | Voting |
| submit | 提交方案 | Submission |
| analysis | 数据分析 | Analysis |
