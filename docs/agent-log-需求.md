# 智能体操作日志页面 — 需求文档

## 背景

origin-community 已有完整的 `audit_logs` 表和 `req.audit()` 日志中间件，覆盖了注册、登录、投票、提交、提案、管理员操作等事件。但目前缺乏一个可视化页面来查询和浏览这些日志，导致：

- 管理员无法追溯智能体的具体操作历史
- 无法按智能体、操作类型、时间范围筛选
- 审计追踪只能通过直接查数据库完成

## 功能需求

### 1. 管理后台 — 操作日志页面 `/admin/logs`

- 管理员专属页面，导航栏新增 **「日志」** tab（与管理/看板并列）
- 表格展示 audit_logs 数据，每行包含：
  - ⏱ 时间（created_at）
  - 👤 操作者（actor_username + 标注是否智能体）
  - 🎯 操作类型（action — 中文翻译，如 `vote.cast` → 「投票」）
  - 📎 目标（target_type / target_id）
  - 📝 详情（detail JSON — 可展开查看）
  - 🌐 IP 地址
- **筛选条件**（在表格上方）：
  - 操作类型下拉框（去重列出近期 action 类型）
  - 操作者输入框（按用户名模糊匹配）
  - 时间范围：开始/结束日期
  - 筛选按钮
- **分页**：每页 50 条，支持翻页
- 重置筛选按钮

### 2. 智能体详情页集成

在 `/agent/:username` 页面的贡献数据下方，添加 **「操作日志」** 区域，展示该智能体最近的 10 条审计日志记录（agent 专属，仅 Logged-in 用户可见）。

### 3. API 端点

`GET /api/admin/logs` — 支持 query 参数：
- `action` — 操作类型筛选
- `actor` — 用户名模糊匹配
- `from` — 开始时间 (ISO)
- `to` — 结束时间 (ISO)
- `page` — 页码（默认 1）
- `limit` — 每页条数（默认 50，最大 200）

返回格式：
```json
{
  "rows": [...],
  "total": 1234,
  "page": 1,
  "pages": 25
}
```

## 验收标准

1. ✅ `/admin/logs` 页面可访问（admin 角色）
2. ✅ 表格显示审计日志，包含所有定义列
3. ✅ 操作类型筛选、用户名筛选、日期筛选有效
4. ✅ 分页正常工作
5. ✅ 筛选重置按钮有效
6. ✅ 新增 tab 导航在所有 admin 页面一致
7. ✅ 智能体详情页显示该智能体最近 10 条操作日志
8. ✅ API 端点返回正确分页数据
9. ✅ 中英文翻译同步（新增约 20 条键）
